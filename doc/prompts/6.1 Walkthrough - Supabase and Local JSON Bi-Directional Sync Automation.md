# Walkthrough: Supabase & Local JSON Bi-Directional Sync Automation and Featured Gallery Reconnection

## Overview
Resolved the issue where updates to `json/featured.json` did not appear on the website, explained the dynamic relationship between Supabase live data and local JSON fallback files, and delivered an automated 1-click synchronization engine (`scripts/sync-database.js` with `sync.bat` and `json/sync.bat`).

---

## Changes

### 1. Root Cause Resolution
- **Supabase-First Priority**: The Single Page Application router (`js/spa-controller.js`) fetches approved records directly from Supabase `public.portal_resources` for all categories. If records exist in the database, local `json/*.json` files are bypassed.
- **Featured Gallery Disconnection**: `loadFeatured()` in `js/data-renderer.js` previously only evaluated star rankings or pulled top 3 items across category lists, completely skipping `featured.json` and Supabase `category = 'featured'`.
- **4-Tier Fallback in `loadFeatured()`**:
  1. Checks Supabase `portal_resources` where `category = 'featured'`.
  2. Checks Supabase `resource_star_rankings` (if >= 20 items exist).
  3. Checks local `json/featured.json`.
  4. Falls back to top 3 items from each category dataset.

### 2. Bi-Directional Database Sync Automation
- **Sync Script ([`scripts/sync-database.js`](../../scripts/sync-database.js))**:
  - Automatically loads Supabase configuration from `env-config.js` or `.env`.
  - Supports `smart sync` (default), `push` (JSON -> Supabase), and `pull` (Supabase -> JSON).
  - Handles all 11 catalog datasets (`featured.json`, `guidance.json`, `materials.json`, `tools.json`, `community.json`, `official.json`, `portfolios.json`, `courses.json`, `capstones.json`, `mentors.json`, and `talent.json`).
  - Compares file `mtime` with Supabase `updated_at` to keep the newest version.
  - Interactive prompt for `SUPABASE_SERVICE_ROLE_KEY` with automatic saving to gitignored `env-config.js` for future 1-click runs.
- **One-Click Batch Files**:
  - Root: [`sync.bat`](../../sync.bat)
  - Directory: [`json/sync.bat`](../../json/sync.bat)
