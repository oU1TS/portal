# Implementation Plan - Dynamic Data Population via JSON

This plan outlines the design and steps to convert the static list items in the oU1TS Portal HTML pages into dynamic content loaded from JSON files. This simplifies content updates, standardizes page rendering, and integrates star ratings smoothly with dynamic content.

## User Review Required

> [!IMPORTANT]
> **Page-Specific Variable Structures**:
> Each page will have a corresponding JSON file under the `json/` directory. We will maintain the exact HTML markup for each page but generate the elements dynamically in JavaScript.
>
> **Star Rating Integration**:
> Since `Stars.js` depends on elements having `data-resource-id` attributes and runs after the DOM is ready, we will ensure that our dynamic rendering runs *before* calling `Stars.init(pageType)`. This ensures that stars can be toggled and sorted correctly.
>
> **Contributions Page**:
> Currently, `contributions.html` fetches data dynamically from a Google Sheet. We will create a local `json/contributions.json` file containing the mock/actual data schema and update the page to load from it instead (or keep the option for Google Sheet if needed, but default to local JSON to match the other pages).

## Proposed Changes

### 1. JSON Data Files
We will create the following JSON files in `json/` to store data:
- `json/community.json`
- `json/courses.json`
- `json/contributions.json`
- `json/guidance.json`
- `json/inspirations.json`
- `json/materials.json`
- `json/official.json`
- `json/portfolios.json`
- `json/tools.json`
- `json/featured.json` (for the index.html marquee)

### 2. JS Dynamic Loader
We will create a helper script `js/data-renderer.js` to:
- Detect the current page context or take a configuration input.
- Fetch the appropriate JSON.
- Construct and append HTML nodes while maintaining original CSS classes and attributes (such as `data-resource-id`).
- Automatically invoke `Stars.init(...)` after rendering is completed so that star counts, user starred state, and sorting work perfectly.
