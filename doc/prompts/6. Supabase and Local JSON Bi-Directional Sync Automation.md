### What Has Been Fixed & Added

#### 1. Reconnected Featured Projects in [`js/data-renderer.js`](file:///d:/GitHub/[oU1TS]/portal/js/data-renderer.js)
`loadFeatured()` now follows a 4-tier fallback hierarchy:
1. **Supabase `portal_resources`**: Checks for items where `category = 'featured'`.
2. **Supabase `resource_star_rankings`**: Checks top starred items across all categories (if 20+ exist).
3. **Local [`json/featured.json`](file:///d:/GitHub/[oU1TS]/portal/json/featured.json)**: Reads your curated featured initiatives directly if offline or not in the DB.
4. **Category Pool Fallback**: Samples top 3 items from each category dataset.

#### 2. Bi-Directional Database Sync Automation ([`scripts/sync-database.js`](file:///d:/GitHub/[oU1TS]/portal/scripts/sync-database.js))
A complete Node.js sync engine supporting all 11 datasets (`featured.json`, `guidance.json`, `materials.json`, `tools.json`, `community.json`, `official.json`, `portfolios.json`, `courses.json`, `capstones.json`, `mentors.json`, `talent.json`):
- **Smart Sync (`sync` - Default)**: Compares local file modification timestamps (`mtime`) with Supabase `updated_at`. Whichever is newest automatically updates the other.
- **Push (`push`)**: Force-uploads local JSON datasets to Supabase using batched upserts (`on_conflict=id`).
- **Pull (`pull`)**: Force-downloads approved records from Supabase and updates local JSON files.

#### 3. 1-Click Batch Launchers
Added two Windows batch files for instant execution:
- [`sync.bat`](file:///d:/GitHub/[oU1TS]/portal/sync.bat) in the project root.
- [`json/sync.bat`](file:///d:/GitHub/[oU1TS]/portal/json/sync.bat) directly inside the `json/` folder.

You can simply **double-click** either batch file in Windows File Explorer to run a Smart Sync.

> [!NOTE]
> **Pushing to Supabase (`SUPABASE_SERVICE_ROLE_KEY`)**:
> Reading/pulling data works immediately with your existing public `anon` key. To write/upsert changes to Supabase (due to Row Level Security), the script requires your `SUPABASE_SERVICE_ROLE_KEY`. The first time you push, the script will prompt you for this key (found in **Supabase Dashboard → Project Settings → API → service_role secret**) and offer to save it into [`env-config.js`](file:///d:/GitHub/[oU1TS]/portal/env-config.js) (which is gitignored). Once saved, all future syncs are completely 1-click and zero-prompt.
