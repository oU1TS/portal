# Walkthrough: Google Sheets Form Submissions Tracking, Admin View Switcher & User Delegation

We have streamlined and expanded the oU1TS Portal CMS architecture: removing the redundant modal in favor of an expansive native **Portal Admin CMS** view (`#cms`), optimizing the mobile interface with shortened icon-only tab buttons and a submissions dropdown filter, reinforcing administrative workflows, and adding canonical URL tags with automated legacy Netlify domain redirection.

---

## 1. What Was Created & Configured

### 1. Canonical URLs & Netlify Domain Redirection
- **Automated Client-Side Redirection ([`index.html`](../../index.html) & [`contributions.html`](../../contributions.html))**:
  - Attached an inline redirector script in `<head>` intercepting visits from `ou1ts-portal.netlify.app` and `ouits-res.netlify.app`.
  - Automatically redirects users to `https://ou1ts.github.io/portal/` while fully preserving subpaths (e.g. `contributions.html`), query strings (`window.location.search`), and SPA hash routes (`window.location.hash`).
- **Canonical Tags ([`index.html`](../../index.html) & [`contributions.html`](../../contributions.html))**:
  - Injected `<link rel="canonical" href="https://ou1ts.github.io/portal/">` into `index.html`.
  - Injected `<link rel="canonical" href="https://ou1ts.github.io/portal/contributions.html">` into `contributions.html`.

### 2. Dedicated Wide Layout for Portal Admin CMS
- **Expanded Dimensions ([`style.css`](../../style.css))**:
  - Configured `#cmsView.category-page` with `max-width: 1440px` and `width: 95%` (expanding past the default 900px category page boundary).
  - Enhanced `.cms-inline-workspace` with frosted glass backdrop (`rgba(15, 23, 42, 0.7)`), 20px border radius, and generous 2rem padding for tables and submission cards.
- **Elimination of Redundant Floating Modal ([`index.html`](../../index.html) & [`js/cms.js`](../../js/cms.js))**:
  - Converted the header "Admin CMS" launcher button into a direct hash anchor (`<a href="#cms">`), unifying the CMS experience into the dedicated SPA view.
  - Removed duplicate `#adminCmsModal` outer HTML from `injectModal()`, keeping individual sub-modals only for focused resource and user editing.

### 3. Mobile Tab Buttons Shortening
- **Icon + Badge Layout on Small Screens ([`js/cms.js`](../../js/cms.js) & [`style.css`](../../style.css))**:
  - Wrapped tab text labels in `<span class="cms-tab-label">...</span>` and provided accessible `title` attributes on all 4 buttons: Submissions & Approvals, Content Manager, Feedback Inbox, and Admin User Selector.
  - On mobile screens (`max-width: 768px`), automatically hid `.cms-tab-label` (`display: none !important`), allowing all four tab buttons to fit neatly across the screen without wrapping or horizontal overflow.

### 4. Mobile Dropdown Filter & Submission Card Accordions
- **95% Container Width & Compact Padding ([`style.css`](../../style.css))**:
  - Maintained `.cms-inline-workspace` at `width: 95% !important; max-width: 95% !important; margin: 0.5rem auto !important;` with reduced padding (`0.85rem 0.65rem`) on mobile viewports (`max-width: 768px`).
  - Styled `#cmsView.category-page` with `padding: 1rem 0 !important;` for proper centering.
- **Unified Submissions Status & Feedback Dropdown ([`js/cms.js`](../../js/cms.js) & [`style.css`](../../style.css))**:
  - Consolidated all submission filters—including Feedbacks—into a single `<select id="cmsMobileSubFilter">` dropdown on mobile (`All Submissions`, `⚠️ Needs Approval`, `✅ Already on Website`, and `💬 Feedbacks`).
  - Full-width mobile select dropdown eliminates clutter and provides instant one-tap filtering.
- **Collapsible Submission Card Accordions ([`js/cms.js`](../../js/cms.js) & [`style.css`](../../style.css))**:
  - On mobile, `.cms-submission-card` behaves as an accordion:
    - Initially shows only `.cms-sub-card-header` (category badge, row number, status tag, project title, and animated chevron).
    - Tapping the header triggers `CMS.toggleSubmissionCard()`, smoothly expanding `.cms-sub-card-body` to reveal details, submitter metadata, URLs, and action buttons.
    - Preserved full card view and multi-column grid on desktop screens.

### 5. Google Sheet Submissions Styling & Admin Safeguards
- **Submitter Social Links**: Styled with `.cms-social-link` and `.cms-sub-meta a` in soft sky-blue (`#93c5fd`, hover `#ffffff`).
- **Role Selector & Button Styling**: Implemented glassmorphic `#cmsUserRoleFilter` dropdown with custom SVG chevron and 32x32px `.cms-btn-icon.edit` buttons.
- **Sole Admin Protection**: Disabled the "Revoke" button with a lock icon when `adminCount <= 1`, backed by runtime verification in `CMS.toggleUserAdmin()`.
- **Regular User Modal Addition**: Modal adds regular members only (`isAdmin = false`), reserving role promotions to the user list table.

## 2. Setup Guide for Supabase SQL Editor

1. Open your **Supabase Dashboard** → **SQL Editor**.
2. Run [`doc/query/query-7-admin-user-delegation.sql`](../query/query-7-admin-user-delegation.sql) to install the user addition and delegation stored procedure.
3. If not run yet, run [`doc/query/query-6-portal-sheet-submissions.sql`](../query/query-6-portal-sheet-submissions.sql) for form submissions tracking.
4. Open the portal at `http://127.0.0.1:5500/#cms` to test the wide CMS layout and mobile responsive controls!
