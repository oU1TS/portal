# Walkthrough - Dynamic Data Population via JSON

All static list elements on the portal pages have been converted to load dynamically from localized JSON files under `json/`. 

## Changes Made

### 1. New JSON Files
We created individual JSON files containing clean data structures for the page entries:
- [materials.json]([oU1TS]/portal/json/materials.json)
- [community.json]([oU1TS]/portal/json/community.json)
- [courses.json]([oU1TS]/portal/json/courses.json)
- [guidance.json]([oU1TS]/portal/json/guidance.json)
- [inspirations.json]([oU1TS]/portal/json/inspirations.json)

- [tools.json]([oU1TS]/portal/json/tools.json)
- [featured.json]([oU1TS]/portal/json/featured.json)

### 2. Universal Data Renderer
- Created [data-renderer.js]([oU1TS]/portal/js/data-renderer.js) to load JSON data asynchronously based on the `data-page` attribute on the script tag.
- It dynamically generates the HTML nodes, retaining full compatibility with `Stars.js` (including attributes like `data-resource-id`).
